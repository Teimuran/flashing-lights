# Flashing Lights

A Telegram bot written in **Kotlin** for issuing and managing tickets for club shows and music events.

## Tech Stack
- **Language:** Kotlin
- **Build System:** Gradle (Kotlin DSL)
- **Infrastructure:** Docker, Docker Compose

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/Teimuran/flashing-lights.git
cd flashing-lights
```

2. Set up the required environment variables (e.g., Telegram Bot Token).

3. Build and start the service using Docker Compose:
```bash
docker compose up -d --build
```
